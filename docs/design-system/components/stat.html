Stat

One figure in large serif italics beside a forest label, such as “Completed sales” on the profile and “Active listings” on the shop page, stacked between line rules.

Overview

sy-stat is the landing page’s stats row: a Fraunces 600 italic value at --font-size-5xl with a semibold forest label on its baseline. Group several in a .stats stack, which draws a line above, below and between them (L2-031).

Anatomy

  1. Value in --text-display, italic, tabular figures
  2. Label in --text-label, forest
  3. Line rules from the .stats stack

Variants

.stats--compact: the same stat at h3 size in a row without rules, for the profile head.

Sizes

Display (default) and compact (h3, in a row).

States

Static. While loading, the page shows skeleton--title and skeleton--text in place of value and label.

Responsive behaviour

The stack is always one column; the compact row wraps.

Theming

The value follows --color-fg-default; the label uses --color-fg-forest (forest-600 light, forest-300 dark).

Accessibility

Value and label are read in order as text; no role is needed.

Forest label on paper

Content

Short label in sentence case; money always with cents.

Do and don’t

  • Do keep a stack to two to four stats.
  • Don’t put actions inside a stat.
