Status

A plain pill in sentence case, tinted with its status colour: draft, active, reserved, sold, removed or info.

WCAG 2.2 AAStatus: stableSince v0.10

Overview

sy-status: A plain pill in sentence case, tinted with its status colour: draft, active, reserved, sold, removed or info. Added with resolve-order-problems (L2-036).

Anatomy

  1. Pill: --radius-full, the status background tint
  2. Status word in --text-label, sentence case, the status foreground

Variants

Draft Active Reserved Sold Refunded Delivered
Draft, active, reserved, sold (ink), removed and info.

Sizes

One size.

States

Static. Tones: draft, active, reserved, sold, removed, info.

Responsive behaviour

Fills its column; text wraps.

Theming

Uses role tokens only, so both themes follow.

Accessibility

The word carries the meaning; colour only repeats it. No dot, no capitals.

Content

One word, the status as the product names it.

Do and don’t

  • Do compose it from @sycapooke/components.
  • Don’t rebuild its markup in a feature library.

Tokens

--radius-full, --text-label, the --color-*-bg and --color-*-fg pairs of success, warning, danger and info, --color-bg-subtle and --color-fg-muted (draft), --color-bg-inverse and --color-fg-inverse (sold).

Code

<sy-status tone="removed">Refunded</sy-status>

Source: src/frontend/projects/components/src/lib/status/.
