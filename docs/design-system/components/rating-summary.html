Rating summary

The reviews line beside the founder: “No reviews yet” until reviews are published.

WCAG 2.2 AAStatus: stableSince v0.9

Overview

sy-rating-summary shows the founder's reviews line in the profile header and the founder summary. While review authoring is deferred there are none, so it reads "No reviews yet". The rated variant (stars, average, count) is retired: no mock uses it, and it returns with the reviews feature.

Anatomy

  1. The muted text "No reviews yet"

Variants

No reviews yet
No reviews yet (the only variant).

Sizes

One size, body small.

States

One state, static. Not interactive.

Responsive behaviour

Never wraps; the same at every width.

Theming

Muted foreground colour in both themes.

Accessibility

"No reviews yet" is plain text with no role.

Content

Always "No reviews yet"; never "0.0" or empty stars.

Do and don't

  • Do show "No reviews yet" rather than empty stars.
  • Don't count hidden or unpublished reviews.

Tokens

--color-fg-muted, --space-1.

Code

<sy-rating-summary [rating]="profile.rating" />

Shows "No reviews yet" while count is 0. Source: src/frontend/projects/components/src/lib/rating-summary/.
