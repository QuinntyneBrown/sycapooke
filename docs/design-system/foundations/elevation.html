Foundation · Heirloom

Elevation

One shadow and a fixed z-order. Heirloom is flat: surfaces are told apart by colour and line, not by depth.

WCAG 2.2 AAStatus: stableHeirloom design system

Overview

The landing page draws one shadow, shadow-sm (0 1px 2px 0 rgb(0 0 0 / .05)), under the search well. Heirloom keeps it as --shadow-1 and aliases every other level to it; nothing lifts, presses or floats. Cards and listing cards have no shadow at all; dialogs, sheets, menus, toasts and the consent banner carry this one soft shadow with a line border.

Usage

  • Never set a raw z-index.
  • Listing cards, cards, panels and photo wells have no shadow; a line border or a cream fill separates them from paper.
  • Only overlays (dialog, sheet, menu, popover, toast, consent) and the search well use --shadow-1.
  • Nothing changes shadow on hover or press; hover changes colour only.
